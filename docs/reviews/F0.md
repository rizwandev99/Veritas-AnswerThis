## Design System Compliance (Section 4)

- **Semantic CSS Variable Tokens**: No raw hex in components (`var(--background)`, `var(--surface)`, `var(--accent)`, `var(--success)`, `var(--warning)`, `var(--danger)`).
- **Anti-FOUC Theme Script**: Inline script in `apps/web/app/layout.tsx` guarantees zero flash of unstyled theme on initial load.
- **Components Built**: `Button`, `IconButton`, `Input`, `Badge`, `Card`, `Skeleton`, `Tabs`, `Tooltip`, `ProgressStepper`, `ThemeToggle`.
- **Responsive**: 360px, 768px, and 1280px+ breakpoints supported with full flex/grid layouts.

## Non-Functional Requirements (Section 12)

- **NFR3 (Reliability)**: Standardized JSON error response format (`code`, `message`, `details`) implemented in `apps/api/app/core/errors.py`.
- **NFR4 (Security)**: Strict CORS headers and preflight handling tested in `apps/api/tests/test_cors.py`.
- **NFR5 (Observability)**: Structured JSON logging middleware propagating `X-Request-ID` tested in `apps/api/tests/test_logging.py`.
