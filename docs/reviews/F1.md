## Non-Functional Requirements (Section 12)

- **NFR3 (Reliability)**: Typed error responses and automatic retry with exponential backoff on OpenAlex timeouts/5xx.
- **NFR4 (Security)**: Normalized queries sanitize malicious or malformed input.
- **Zero Cost Compliance**: Uses 100% free OpenAlex REST API with polite pool email headers and zero external paid dependencies.
