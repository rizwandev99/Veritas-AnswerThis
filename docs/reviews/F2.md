## Non-Functional Requirements (Section 12)

- **NFR2 (Pipeline Latency)**: Tokens streamed asynchronously via HTTP SSE without buffering (`X-Accel-Buffering: no`).
- **NFR3 (Reliability)**: Typed SSE error events preserve partial generation and error messages.
- **NFR4 (Security)**: Prompt wrappers treat sources as untrusted input with `<SOURCES>` delimiters to mitigate prompt injection.
